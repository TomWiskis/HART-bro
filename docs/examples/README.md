# Искусственные данные для проверки Excel

`TEST-ONLY-walk-100-devices.xlsx` — **100 искусственных приборов**, не результаты измерений и не заводские паспорта. Все марки и значения заполнены для проверки формата. Единственный лист «Приборы» содержит ровно пять согласованных колонок; некоторые поля намеренно пусты. Номера сохраняют ведущие нули, даты — точность день / месяц / год.

Рядом — ожидаемые значения TSV и результат независимого чтения openpyxl. Воспроизведение:

```sh
./gradlew :hart-core:walkExampleReview -PwalkReviewDir=/tmp/hart-walk-review
python3 tools/validate_walk_xlsx.py /tmp/hart-walk-review
```

Реальная контрольная сессия `148d023e-8504-47ef-98a8-e3f5faba7954` проверяется отдельно: [описание экспорта](../EXPORT_0.3.1.md). Она не смешивается с искусственной ведомостью обхода.
