# Проверки HART-бро 0.3.0

## Локальная сборка

JDK 21, Android SDK/API 36, Build Tools 36.0.0, Gradle 8.13. Команда:

```sh
./gradlew :hart-core:test :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug --offline --no-daemon -Pkotlin.compiler.execution.strategy=in-process
```

Итог: BUILD SUCCESSFUL, 125 actionable tasks. JVM: **139 тестов, 0 failures, 0 errors, 0 skipped**. Android Lint: **0 ошибок, 1 предупреждение** `NewerVersionAvailable` для закреплённой зависимости coroutines; обновление зависимостей вне задачи не выполнялось. Основной APK и APK инструментальных тестов собраны.

Проверяются все прежние протокольные регрессии, реальные golden vectors Метрана, длина/XOR/фрагментация/таймауты/отмена, 60-секундный recovery. Новые JVM-проверки покрывают команду 15/ревизии 5–7/точность/обратный диапазон/недостоверность, TAG/description/long TAG, частичные ответы/исходные коды/сравнение; подключение без сессии/явный старт/повторный ID/сохранение Bluetooth; архивные v1 и v2/метаданные/удаление; CSV с отрицательными значениями, русскими именами единиц, BAD/ABSENT/UTC/UTF-8, 10000 точек без сокращения; статистику по исходным точкам/разрывы.

На API 36 инструментальные сценарии проверяют:

- 5 реальных минут с видимой Activity, 5 минут с выключенным экраном, 5 минут с Settings в foreground; новые измерения/рост истории, фактические screen power и foreground package проверяются каждые 5 секунд; тестовый таймаут автоматического выключения экрана временно увеличен. Затем Home/возвраты/recreate/пустой service intent: та же сессия, ID и уведомление.
- Закреплённый выход из длинного архива и Android Back при продолжающемся мониторинге.
- Кнопку отдельного старта/паузу/продолжение/сохранение/завершение/новый прибор через прежний Bluetooth.
- Первоначальное подключение в фоне: успех с READY без истории и конкретная ошибка идентификации без ложной сессии.
- Краткую потерю HART и отдельную потерю Bluetooth: восстановление без дублирования сессии; исправный транспорт при HART-ошибке не переподключается.
- Уничтожение службы: временная история остаётся до ручного решения/сохранения.
- UI журнала: название/комментарий/поиск/сравнение/отмена удаления/подтверждённое удаление нескольких записей.
- PDF с одним параметром, несколькими несовместимыми единицами и реальными разрывами, длинную сессию 10000 точек, пересекающую границу суток UTC, с датами на оси. Android PdfRenderer открывает каждую страницу, проверяет A4, наличие видимого содержимого и извлечение кириллицы; CSV сверяется с количеством всех исходных измерений.

Транспорт этих сценариев находится только в androidTest. Успех эмулятора не означает аппаратную проверку Bluetooth-модема. Локального KVM нет, локальное выполнение Android-инструментальных тестов не заявляется.

Устанавливать опубликованный APK поверх 0.2.1 без удаления/очистки данных, предварительно вручную сохранив важную текущую сессию. Для 0.2.0 сертификат также совпадает. Потерянный ключ 0.1.1 не восстановлен; обновление с неё с сохранением данных этим сертификатом не обещается. Произвольный CI APK может иметь другой debug-сертификат.
