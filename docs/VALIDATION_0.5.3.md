Запись 18 сохраняет остальные packed-поля побайтно, 22 проверяется чтением 20. Потеря ACK не создаёт повтор записи, неподтверждённое изменение не становится успехом, защита/изменённое исходное значение/замена прибора блокируют TX. Команда 43 на документированном тестовом профиле отправляется один раз, проверяются три PV; неизвестный профиль не получает пробной записи, неизменившийся PV не признаётся успехом. Журнал переживает прерывание без повторных команд, индивидуальное удаление сохраняет другие записи.

Кэш диагностики сохраняется при переподключении того же прибора; при новом Device ID возможности определяются заново и все запросы используют новый длинный HART-адрес. Это подтверждено отдельным транспортным тестом.

Сохранены все прежние проверки HART 0/неполного кадра/позднего XOR, однократности 35/контрольного чтения/неизвестного результата, сессий/отчётов/обхода. Проверены ручной масштаб, постоянная ширина прокрутки и отсутствие самопроизвольного включения следования при zoom.

## Ограничения

Автоматические записи выполняются на программных имитаторах транспорта. Физические VIATOR и датчик в этой среде отсутствуют. Device ID / Meter ID — один серийный номер по уточнению пользователя; универсальной записи этого ID нет. Ноль разрешён первоначально для Viatran 970 HART5 DEV_REV2; неизвестным моделям команда не отправляется. Другие единицы выбираются, но для записи нужна документированная поддержка. Редактируемая HART Date может быть заполнена по шильду, происхождение ранее прочитанной даты не удостоверяется.
