# HART-бро 0.5.2 — интерфейс и поведение

Обновление существующей 0.5.1. Bluetooth Classic SPP/RFCOMM, декодер кадров, подтверждение подключения и исправление повторной идентификации не переписаны.

- Постоянный компактный Bluetooth-индикатор в заголовке показывает имя выбранного/фактически подключённого коммуникатора, подключение, разрыв и восстановление. Имя сокращается с многоточием; полное имя и статус доступны средствам доступности. При конфигурировании учитывается состояние принадлежащего операции транспорта, включая закрытие reader.
- Монитор показывает имя достоверно определённой модели либо нейтральное «HART-датчик» с производителем/ID, свежесть HART-обмена, PV и ток в одной колонке. Ток берётся из команды 3; PV не выводится из тока. При опросе командой 9 ток обновляется отдельным чтением 3, а не остаётся бессрочным стартовым снимком. Неподдерживаемые значения не подменяются PV.
- «Открыть диагностику» открывает самостоятельный экран, не HEX. Через существующую исключительную очередь читаются 0/конфигурация/диапазон/измерения; мониторинг временно приостанавливается с разрывом истории и возвращается в прежнюю сессию. Обнаружение другого прибора блокирует объединение. Необязательные недоступные поля имеют явную ошибку. HEX остаётся отдельной вкладкой.
- В диагностике есть производитель, единственный Device Type, ID, HART/ПО, реальные переменные, ток, диапазон/пределы/защита, конфигурация и известные статусы текстом. Дата чтения, повтор Device Type, отдельный необработанный 0x40 и фраза «по данным команды 15» удалены из обычного представления. Редактируется только уже поддержанный диапазон; остальные поля доступны для чтения.
- Диапазон: поля в одной строке, между ними «—», справа список единиц. Первое фокусирование выделяет число, первый ввод заменяет его; далее курсор работает обычно. Добавлены компактные кнопки знака для цифровых клавиатур без минуса. Отдельное подтверждение показывает старое/новое значения, затем выполняется единственная 35 и контрольные чтения.
- График: начальный масштаб 60 с, постоянная ширина окна, следование актуальному времени, прокрутка в прошлое без изменения масштаба и автоматический возврат к следованию около правого края. Кнопки масштаба независимы от опроса; в истории масштабируется центр просматриваемого участка. Выбранное окно/масштаб/следование хранятся отдельно от данных сессии и переживают смену вкладок и Activity recreate. Видимые точки — только PV; дополнительные переменные остаются в диагностике и прежних архивных графиках с разными шкалами единиц. Измерительный диапазон находится справа над построением, отдельно от численной оси Y.
- При отсутствии обмена новых точек нет; текущие карточки обозначают старые значения как неактуальные. История не обрезается по окну, сегменты разрывов не соединяются. Обратный отсчёт находится только рядом с «Переподключение» во время восстановления; предел 60 с сохранён.
- История конфигурирования: одна компактная запись на операцию, локальные дата/время слева, изменения строками, результат ✓ / ✕ / ? справа; доступны подробности, TXT и проверка неизвестной операции чтением. Удаление одной записи или всей истории требует подтверждения и не обращается к транспорту. Выполняемое устойчивое намерение удалить нельзя.

## Граница поддержки единиц

Наличие размерности, HART-кода или корректной математической конверсии **не доказывает**, что конкретный прибор принимает запись этой единицы. Универсальные чтения 0/14/15 не возвращают перечень всех допустимых для записи единиц.

Поэтому в текущей производственной конфигурации список содержит только прочитанную единицу. Произвольные альтернативы не предлагаются, команда 44 не добавлялась. В механизме диапазона предусмотрен явный поставщик документированных возможностей конкретного прибора; лишь он может разрешить дополнительные единицы для той же операции 35. Пока такого подтверждённого профиля нет, фактическая смена единиц недоступна. В форме это объясняется текстом.

Преобразования давления Pa/kPa/MPa/bar/mbar и температуры °C/°F/°R/K реализованы отдельно от формы и транспорта, включая смещения и проверку Float32. На имитаторе проверена единая запись границ/единицы при явно заданной поддержке и обязательное подтверждение фактическими чтениями. Изменение чисел или выбор пункта формы сами по себе ничего не записывают.

## Совместимость

Application ID и прежний сертификат сохраняются, versionCode 10. Форматы сессий, ведомостей, конфигурационных снимков и журнала операций не изменены; очистка или миграция пользовательских данных не требуется. Сохранение измерительной сессии остаётся ручным. Архивы/PDF/CSV/XLSX, обход, неизвестные результаты записи, проверка другого ID и однократность 35 сохранены. Автоматические записи выполняются только на программных транспортных имитаторах; физическое оборудование не используется.
