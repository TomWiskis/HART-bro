## Реальный ответ Метрана

Fixture `hart-core/src/test/resources/metran-command0.hex` содержит ровно предоставленные пользователем байты, без исправления контрольной суммы:

```text
FF FF FF FF 06 80 00 18 00 00
FE 99 72 05 07 07 28 08 00 5F CA 7F 05 09 00 2C 00 00 99 00 99 01 65
```

33 байта; разделитель 06; короткий адрес 80; команда 0; byte count 0x18 = 24, включая два байта статуса; данные команды — 22 байта; XOR 0x65 совпадает. Парсер сохраняет четыре FF, принимает полный кадр и формирует предупреждение о нестандартной преамбуле.

Разбор: HART 7, manufacturer 0x0099 «Метран», полный тип 0x9972, ID 0x5FCA7F, ревизия команд устройства 7, ПО 40, hardware revision 1, physical signaling 0. Уникальный адрес для primary master — `99 72 5F CA 7F`.

Проверены все 32 двухчастных разбиения, каждый неполный префикс, приём по одному байту и 250 детерминированных случайных разбиений. Дополнительно клиент воспроизводит команду 0 и тестовую команду 1 в 30 вариантах фрагментации. Значение команды 1 в тесте **синтетическое**: оно проверяет переход на длинный адрес и декодирование PV, не считается измерением реального датчика и не попадает в APK.

Повреждённые сумма/данные/длина не принимаются как валидный кадр. Сильно завышенная длина остаётся неполным пакетом до явного сброса/таймаута; парсер не угадывает границы по FF внутри payload. Переполнение буфера диагностируется отдельно. Для приёма допускаются четыре и более FF, передаваемые запросы сохраняют минимум 20 FF.

## Оставшаяся проверка

Пользователь уже получил реальный ответ 0 через VIATOR в 0.1.0; его отбрасывание было ошибкой парсера. Для 0.1.1 требуется подтвердить физическое чтение PV командой 1, единицы, статус, работу UI/разрешений и разрыв соединения на конкретном телефоне. Подготовлен [один сеанс повторного испытания](METRAN_RETEST_0.1.1.md).

Формат разделителя, expansion bytes и 16-битного Expanded Device Type дополнительно сверен с открытым [HART-IP pass-through диссектором Wireshark](https://github.com/wireshark/wireshark/blob/master/epan/dissectors/packet-hartip.c). Это справочная реализация, не замена нормативной спецификации FieldComm. Официальные сайты VIATOR/HART остаются недоступны в исходной сетевой политике; их прочтение не заявляется.

USB OTG/ЭнИ-406, команды записи, калибровки, сброса статусов, непрерывный мониторинг и графики не реализовывались. После выпуска 0.1.1 работа останавливается для аппаратного испытания Метрана.
