# Результаты проверки прототипа

Дата: 28 октября 2026 года. Проверки выполнены в текущем облачном экземпляре; запуск на физическом телефоне и аппаратная приёмка **не выполнены**.

## Среда и сборка

- Eclipse Temurin JDK 21.0.9; Gradle Wrapper 8.13; AGP 8.13.2; Kotlin 2.2.21.
- Официальные дистрибутивы JDK и Gradle проверены по SHA-256, архивы SDK — по контрольным суммам из официального HTTPS-репозитория Google. Проверка TLS сохранена; Java использует доверенные CA управляемой среды.
- Android SDK Platform 36, Build Tools 36.0.0. APK имеет min SDK 29, target SDK 36, application ID `ru.hartbro.app`, версию `0.1.0`.

Успешно выполнен полный набор:

```sh
./gradlew :hart-core:test :app:assembleDebug :app:lintDebug --no-daemon
```

После обновления ресурсов выполнена чистая пересборка **только модуля приложения**, с сохранением зависимостей и результатов неизменённого протокольного модуля:

```sh
./gradlew :app:clean :hart-core:test :app:assembleDebug :app:lintDebug --no-daemon
```

Повторный запуск сохранённого в черновике `install_script` также завершился успешно; Gradle повторно использовал актуальные результаты (`UP-TO-DATE`). Это проверка повторяемости в текущей машине, а не проверка восстановления в новой задаче.

## Тесты и анализ

JUnit XML из `hart-core/build/test-results/test/`: **34 теста, 0 ошибок, 0 падений, 0 пропусков**. Выполнены тесты golden vectors короткого и длинного запросов, потокового разбора, всех границ фрагментации, неверных сумм/длин, переполнения, идентификации HART 5–7, IEEE-754, неизвестных единиц, таймаутов/повторов, отмены, сериализации и фильтрации чужих/накопленных ответов. Это тесты программной логики на синтетических кадрах, не сертификация реализации HART.

Android Lint: **0 ошибок, 1 предупреждение** `NewerVersionAvailable` — доступна новая версия корутин 1.11.0; проект закреплён на проверенной 1.10.2. Ошибки Lint не отключались, baseline не создавался. При debug-сборке готовая библиотека AndroidX `libandroidx.graphics.path.so` упаковывается без удаления символов; NDK для этой операции отдельно не устанавливался.

В итоговом манифесте есть Bluetooth-разрешения, **нет INTERNET**. Проверено отсутствие тестовых классов `SimulatedTransport` и `HartClientTest` в DEX готового APK.

## Что осталось непроверенным

- Установка и интерфейс на Android-телефоне; реальное сопряжение, разрешения, RFCOMM и отмена блокирующих операций на конкретной версии Android.
- Режим передачи и возможная обязательная инициализация VIATOR HM-MT-BT-EX-010041. Недокументированные управляющие последовательности не добавлялись.
- Реальные ответы HART 0/1, цифровая PV и единицы конкретного датчика, соответствие независимому коммуникатору.
- Физические помехи, обрыв петли, выключение модема и поворот/сворачивание на телефоне.
- CI workflow добавлен, но на GitHub в этой задаче не запускался. Эмуляторные/instrumentation-тесты не выполнялись.

JavaDoc API Bluetooth изучен из официального SDK 36. Веб-документация производителя и Android заблокирована исходной сетевой политикой (HTTP CONNECT 403); доступ к сайту спецификаций HART также не входит в исходный allowlist. Документы VIATOR/HART с указанных в ТЗ сайтов не прочитаны. Приложение не объявляется аппаратно совместимым по результатам одной сборки.

Для аппаратной приёмки следуйте [первому испытанию с VIATOR](FIRST_VIATOR_TEST.md). До получения корректных ответов реального датчика критерий готовности этапа 1 остаётся открытым. Этапы 2–5 не реализовывались.

- `start_skill` — расположения инструментов, рабочий каталог, команды проверки и ограничения аппаратной приёмки. Текущая задача уже изолирована, отдельный Git worktree не требуется.

Подготовленные инструменты лежат в `/workspace/toolchains`, Gradle-кэш — в `/workspace/toolchains/gradle-home`. Никакие серверы для сборки или приложения не нужны. Черновик сохраняет инструкции, но не применяет сетевые изменения и не публикует среду. Чтобы использовать новую конфигурацию, просмотрите и сохраните её в настройках среды, затем опубликуйте среду. Публикация и восстановление в новой задаче здесь не проверялись.
