## Изменённые части и оставшиеся ограничения

- `hart-core`: allowlist чтения, новые декодеры/модель, определение возможностей, engine восстановления, временная история/снимки и модель навигации графика; новые тесты.
- `app`: Application/Controller, FGS, монитор/общий Canvas, журнал/подтверждения/диагностика и номер версии.
- `docs`, README, CHANGELOG: восстановленный полный контекст, архитектура, форматы/источники, этот отчёт и комплексный аппаратный план.
- `transport-bluetooth`: работает через прежний транспорт, изменений нет.

Не исполнялись Android instrumentation/эмулятор, реальные жесты/вёрстка на телефоне, фон/Doze, Bluetooth/VIATOR, новые команды конкретного Метрана, установка/обновление APK на устройстве и аппаратное восстановление. Программные тесты графика проверяют данные/навигацию, не служат доказательством Android-отрисовки. Эти проверки объединены в [один аппаратный сеанс](METRAN_TEST_0.2.0.md).

Форматы проверены по открытой реализации FieldComm Group/Wireshark; нормативный сайт недоступен (403), сертификация протокола не заявляется. Назначения SV/TV/QV не угадываются. Предел активной истории 64 МиБ; график прореживает только представление с сохранением экстремумов/разрывов, архив содержит все записи. Android может прекратить процесс, при новом запуске временная сессия не восстанавливается автоматически. Ручные снимки сохраняются.

Версии 0.3+ (экспорт/полный журнал, запись/калибровка, шаблоны/Terminal, USB) не реализовывались. Разработка 0.2.0 остановлена до результатов аппаратного испытания. Настройки облачной среды и её публикация не изменялись.
