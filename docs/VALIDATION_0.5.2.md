## Ограничения и физическое испытание

В производственной конфигурации нет документированного перечня допустимых единиц для конкретных моделей: список содержит только прочитанную текущую единицу. Математическая конверсия не является разрешением записать любую совместимую единицу. Команда 44 не добавлялась. Модель без профиля не угадывается из Device Type: используется нейтральное имя с реальными производителем/ID. Если команда 3 не поддерживается, ток отображается как недоступный, а не рассчитывается из PV.

Реальный VIATOR/датчик к среде не подключался. Автоматические HART-записи выполняются только на программных имитаторах. Возможности записи единиц конкретным устройством, численная точность реального датчика, воздействие на выход 4–20 мА и физическое поведение Bluetooth проверяются отдельно по [сценарию испытания](RETEST_0.5.2.md); для записи сохраняется HARDWARE_TEST_0.5.0.md.
