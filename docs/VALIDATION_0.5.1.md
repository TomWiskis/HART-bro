**198 JVM-тестов, 0 failures / 0 errors / 0 skipped.** Основной и инструментальный APK собраны. Lint: **0 ошибок / 1 прежнее предупреждение NewerVersionAvailable**. Зависимости не обновлялись.

Новые сценарии: начальная ошибка идентификации без сессии и без закрытия здорового RFCOMM; два неудачных повтора и последующее успешное чтение на том же транспорте; переподключение закрытого RFCOMM, уведомление о разрыве и конкурирующие повторные запросы; IOException начальной идентификации с последующим восстановлением; последний XOR внутри срока ответа; отсутствующий XOR и поздние фрагменты после таймаута с независимым новым кадром. Старое ожидание принудительного закрытия после HART-таймаута заменено проверкой сохранения соединения и его явного освобождения при остановке.

Все прежние тесты сохранены, включая команду 35: timeout, плохой XOR, чужой адрес и короткий ACK не вызывают повторной записи; остаются проверочные 0/15, устойчивый журнал, UNKNOWN и защита от двойного подтверждения. Число передач 35 не превышает одного. Новый барьер поздних фрагментов выполняется только перед чтениями, не перед отправкой 35.

Независимый openpyxl подтвердил 269 исходных значений → 68 временных строк без потерь Float32/качества/источников; ведомость на 100 тестовых приборов содержит один лист, 5 колонок и 505 сопоставленных ячеек, сохраняет ведущие нули и точность дат.
