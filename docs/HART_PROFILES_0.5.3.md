# HART: идентификация, TAG, дата и ноль в 0.5.3

## Уточнения задания пользователем

- Meter ID = Device ID = серийный номер. Показывать десятичным числом. Final Assembly Number исключён из нового интерфейса. Универсальной команды изменения Device ID нет: серийный номер доступен для чтения, запись не подменяется командами Message или Final Assembly.
- Дата означает дату производства с шильда; пользователь может заполнить редактируемое HART Date. Это назначение поля в приложении, а не доказательство, что ранее прочитанное значение установлено заводом. Режим обхода и его правила происхождения фактов не изменены.
- Кнопка установки нуля общая для датчиков давления. Команда разрешается только при подтверждённой поддержке конкретной модели/ревизии. Измерение давления само по себе не доказывает поддержку необязательной команды 43.

## Источники и таблица моделей

Идентификаторы проверены по [реестру FieldComm Group](https://www.fieldcommgroup.org/registered-products). Каждая запись `HartDeviceCatalog` содержит идентификатор страницы реестра, доступной по `https://www.fieldcommgroup.org/old-registered-products/<source>`:

| Manufacturer | Device Type | Модель |
|---|---|---|
| 0x99 | 0x9979 | Метран-150 |
| 0x99 | 0x997F | Метран-100 |
| 0x99 | 0x9977 | Метран-303 |
| 0x99 | 0x997E | Метран-280-2 |
| 0x26 | 0x268F, 0x2606 | Rosemount 3051 |
| 0x32 | 0x3201 | Viatran 970 |

Полный тип и Manufacturer сопоставляются вместе. Тип 0x9972 из полевого ответа Метран пока не сопоставлен с подтверждённой моделью: приложение честно оставляет исходный код. Не следует присваивать ему название Метран-150 только по производителю.

## TAG и дата

Формат команды 18 (6 байт packed ASCII TAG + 12 descriptor + 3 Date) и команды 22 (32 байта Long Tag) подтверждён [открытой реализацией FieldComm Group](https://github.com/FieldCommGroup/hipflowapp/tree/master/hipflowapp/Hip_Native/Commands), файлы `cmd_18.h`, `cmd_22.h`. Код приложения написан самостоятельно; исходники источника не копируются.

Дата: день, месяц, год минус 1900. Некорректная/нулевая/FF дата не выводится в быстрой карточке. Перед командой 18 перечитываются все 21 байт команды 13: незатронутые TAG, descriptor или Date сохраняются побайтно. Перед длинным TAG перечитывается команда 20. Если редактируемое значение изменилось после открытия формы, запись отклоняется до отправки. Защита проверяется командой 15. Запись выполняется один раз, затем повторяется идентификация и чтение изменённого поля. Потерянное подтверждение не разрешает повтор записи.

## Установка нуля

Семантика команды 43 — Set Primary Variable Zero, без данных запроса. [HCF_SPEC-151 rev.8](https://raw.githubusercontent.com/biplabro/HART-Protocol-Fundamentals/main/04.%20Resources/HART%3A%20Commands%20manual.pdf), раздел 6.8. Команды 35/37 не заменяют подстройку PV.

Начальный подтверждённый профиль: **Viatran 970, Manufacturer 0x32, Device Type 0x3201, Device Revision 2, HART 5**. Основание: [98MANAL970 Rev.D](https://www.viatran.com/static/media/uploads/manuals/970_manual.pdf), таблица команд (43 — Trim PV Zero), [реестр FCG](https://www.fieldcommgroup.org/old-registered-products/44520f08-1fb2-e811-8153-e0071b66aea1), DEV_REV 2. Остальные модели, включая нерасшифрованный Метран, требуют документации/профиля; команда им вслепую не отправляется.

Перед записью проверяются идентичность, защита, статус прибора, давление PV и доступность пределов сенсора. Пользователь подтверждает приложенное нулевое давление; для абсолютного датчика нужен эталонный вакуум. После одной команды 43 выполняются три чтения PV. Допуск программной проверки — 0,01 % ширины пределов сенсора, не меньше 0,000001 единицы; он явно указан в подтверждении и журнале. Это проверка результата обмена, а не метрологическая поверка. Ответ с ненулевым кодом или неподтверждённый результат не показывается успешным.

## Единицы диапазона

Можно выбрать любой допустимый код единицы (1–249, 253). Команда 35 разрешается лишь для документированного набора единиц конкретного прибора; без профиля известна только текущая единица. Неподтверждённый выбор виден в редакторе, но не отправляется. Формат, подтверждение, журнал и правило «одна команда 35, затем чтение фактического диапазона» сохранены.
