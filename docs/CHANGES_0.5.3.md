# 0.5.3 — быстрый просмотр и параметры

- Отдельная карточка быстрого просмотра: индикатор присутствия, производитель/модель/TAG, Device ID десятичным числом, заполненная дата без подписей, диапазон с отдельным карандашом. Информация открывает диагностику. Ноль и запуск сессии расположены под ней.
- Лёгкая идентификация каждые ~1,5 с без постоянных чтений PV/тока и создания сессии. Замена прибора обновляет конфигурацию. После завершения сессии возобновляется лёгкая проверка. Закрытый RFCOMM восстанавливается; исправный сохраняется при HART-таймауте.
- Таблица моделей с источниками FieldComm Group, с ключом manufacturer + полный Device Type. Неизвестные значения остаются кодами.
- TAG (18), Long Tag (22), Date (18): ввод → подтверждение → одна запись → идентификация и проверочное чтение. В команде 18 сохраняются неизменяемые 21-байтовые поля. Изменённое с момента открытия значение и защита блокируют отправку. Потерянное подтверждение не создаёт повторную запись. Неподтверждённый результат не показывается успешным.
- Типизированная установка нуля командой 43: профиль поддержки, защита, статус, давление, пределы, подтверждение пользователя, одна отправка, три проверочных чтения PV. Общая кнопка присутствует у датчика; без подтверждённого профиля объясняется ограничение.
- Диагностика содержит редактируемые строки TAG/даты, десятичный серийный номер, доступную конфигурацию и фактические статусы/ошибки. Нет пустого Final Assembly Number, служебной переменной 0x40, даты последнего чтения или повтора Device Type.
- Любой допустимый код единицы можно выбрать в редакторе диапазона. Неизвестная поддержка блокирует запись; арифметическое преобразование не разрешает неподтверждённую единицу. Текущая единица первая в списке. Команда 35, её подтверждение и журнал совместимы с 0.5.0–0.5.2 и не повторяются.
- Новые операции хранятся в отдельном устойчивом журнале рядом с прежними записями диапазона. Каждая запись содержит изменение, время, результат проверки; доступно подтверждённое удаление. Прерванная операция восстанавливается как неподтверждённая, без повторения команды.
- Увеличено время актуальности PV/тока: max(15 с, 4 периода). В быстром просмотре состояние устаревших измерений вообще не создаётся.
- Исправлены жест масштабирования, запрет самопроизвольного включения следования при zoom и изменение области временного бегунка во время перетаскивания. Сохранены окно 60 с, возврат к настоящему и Activity recreation.
- Режим обхода, его паспортные правила и экспорт не изменены. USB не добавлялся.

## Ограничения испытательной сборки

1. Device ID / Meter ID — один серийный номер по уточнению пользователя. Универсальная запись Device ID отсутствует в HART; поле доступно для чтения. Запись другого параметра вместо него не выполняется.
2. HART Date пользователь может заполнить как дату производства по шильду. Происхождение ранее записанного в датчике значения не удостоверяется.
3. Поддержка команды 43 первоначально подтверждена для Viatran 970, HART 5, Device Revision 2. Для иных устройств нужны профили по документации производителя. Наличие давления и поддержка HART сами по себе не разрешают команду. В частности, имеющийся Метран 0x9972 пока остаётся без разрешённой установки нуля.
4. Без документированного набора поддерживаемых единиц разрешена запись только в текущей единице. Остальные можно выбрать, но отправка заблокирована.
5. Автоматические проверки используют симуляторы транспорта и Android API 36; физический VIATOR/датчик в рабочей среде отсутствует. Нужны полевые испытания, особенно установившееся нулевое давление, поддержка даты и механика восстановления соединения.
