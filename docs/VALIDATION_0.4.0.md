Новые проверки покрывают 14/16: unsigned24, длину, реальные форматы HART 5/7, потоковую фрагментацию/XOR/неполные кадры, отсутствие ответа и неподдерживаемые команды, частичные паспортные данные при потере RFCOMM. Проверяются Long TAG/резерв 13, диапазон именно из 15, честные неизвестные производители/типы, запрет выдавать ID/номера 14/16/HART Date за заводские поля без подтверждения профиля, связь документированного поля с исходным ответом.

Проверки обхода: А → снятые щупы → Б → А без дубликатов/измерительных циклов/разрыва исправного Bluetooth; один 60-секундный предел Bluetooth и отсутствие скрытых попыток после его истечения; сохранение строк при ошибке черновика; сохранность ручных значений/ведущих нулей/точности дат; принятие нового диапазона только пользователем; неоднозначные/нулевые/совпадающие ID и разделение строк; отдельные постоянные документы и черновики; передача READY-соединения после cancel/join и защита запрошенного старта сессии от неявной отмены, сериализация всех переключений режима, игнорирование запоздалых команд старого экрана, актуальность черновика при конкурирующих callbacks и сохранение номеров-кандидатов после частичных чтений.

Все прежние тесты обычного измерительного reader, реальных golden vectors Метрана, восстановления, графических сегментов, архивов v1/v2, конфигурации, статистики и отчётов сохранены.

## Независимое чтение Excel

`openpyxl` открывает обе настоящие OOXML-книги без предупреждений:

- [Искусственный пример обхода](examples/TEST-ONLY-walk-100-devices.xlsx): ровно один лист «Приборы», 5 колонок, 100 приборов + строка заголовков; проверены все 505 ячеек, фильтр A1:E101, закрепление A2, кириллица, текстовые номера с нулями, пустые поля, полные/частичные даты, отрицательные границы и разные единицы. В примере явно указаны тестовые TAG/марки. [JSON проверки](examples/walk-xlsx-validation.json).
- Реальная сессия `148d023e-8504-47ef-98a8-e3f5faba7954`: **269 исходных значений → 68 точных временных строк → 269 числовых ячеек**. PV 68, SV/TV/QV по 67; первые отсутствующие слоты пусты. Сверены float32, Excel-время UTC, UNVERIFIED, команды, коды единиц/переменных, raw/device statuses. Никаких вымышленных заводских сведений. Входной CSV сохранён без изменения байтов, сведения PDF используются с оговорённой тестовой реконструкцией, не как захваченный бинарный HART-архив. [Подробности](EXPORT_0.3.1.md).

Проверки воспроизводимы командами `:hart-core:walkExampleReview` / `tools/validate_walk_xlsx.py` и `:hart-core:exportControlReview` / `tools/validate_export_control.py`. Ручной запуск Microsoft Excel в облачной среде не заявляется; структура и все значения независимо прочитаны стандартной библиотекой OOXML. Проверка в Microsoft Excel входит в аппаратный сеанс пользователя.

## Граница проверки

Автотесты используют имитаторы. Реальная контрольная сессия 0.3.0 проверяет экспорт, но не является аппаратной проверкой нового обхода или команд 14/16. Производительские соответствия заводским сведениям не выдуманы; без документированного профиля доступны кандидаты и ручной ввод. Полностью одинаковые идентификационные ответы разных физических приборов требуют ручного разделения. Фоновое поведение реального телефона/VIATOR подтверждается в [одном аппаратном сеансе](HARDWARE_TEST_0.4.0.md).

После публикации работа останавливается до результатов этого испытания. Запись параметров, калибровка, multidrop и USB не добавлены.
