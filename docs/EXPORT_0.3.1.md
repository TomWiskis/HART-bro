# Экспорт HART-бро 0.3.1

Исправления экспорта первоначально подготовлены как 0.3.1 и **включены в выпуск 0.4.0** без отдельной публикации 0.3.1. applicationId и формат измерительных архивов прежние. Сами исправления экспорта не меняют HART-протокол, Bluetooth-транспорт и алгоритм получения измерений; отдельный режим обхода 0.4.0 описан в [CHANGES_0.4.0](CHANGES_0.4.0.md).

## Excel как основной формат

Кнопки «Сохранить Excel (.xlsx)» и «Отправить Excel» создают настоящий OOXML workbook. Это ZIP/XML `.xlsx`, а не CSV с другим расширением; макросов, формул, внешних подключений и сетевого обмена в книге нет. Генератор потоковый, без зависимости Office/POI в Android.

В книге один лист «Проверка» с двумя блоками:

1. «Сводная ведомость приборов»: TAG, заводской серийный номер, дата выпуска, тип/марка, настроенный диапазон, HART Device ID. Одна строка на прибор. Из журнала можно выбрать несколько сохранённых проверок и получить одну ведомость. В 0.4.0 режим автоматического обхода использует отдельную пятиколоночную ведомость, не этот полный измерительный отчёт.
2. «История измерений»: точное время получения в UTC и отдельные числовые PV/SV/TV/QV. Единицы входят в заголовки. Для каждого слота отдельно сохранены качество, команда, код единицы, код переменной, исходный статус переменной и статус прибора; нечисловой исходный маркер — в отдельном поле. ID проверки и HART Device ID связывают историю с реестром.

Оба блока — таблицы Excel с автофильтрами. Заголовки выделены, ширина столбцов задана, даты имеют настоящий числовой тип даты Excel. Для небольшой ведомости закреплена область до заголовка истории; для большой — общие верхние строки, а заголовки доступны как заголовки таблиц Excel. Числа используют General, чтобы малые величины не выглядели искусственным нулём. Их исходная точность float32 сохраняется при обратном чтении.

Объединение происходит по точной временной метке, без округления до секунды. Отсутствующий слот даёт пустую ячейку, не ноль и не предыдущее значение. SV и QV не удаляются при равенстве: это отдельные исходные слоты. BAD с конечным значением остаётся числом с отдельным качеством; NaN/Infinity и ABSENT не превращаются в числа Excel, их исходный маркер сохраняется отдельно.

Два разных значения одного слота в один момент не перезаписываются: экспорт сообщает конфликт и предлагает технический CSV. Точные дубликаты одной записи объединяются. Перекрывающиеся снимки одного прибора не объединяются автоматически; выбирайте один полный снимок. История с обратным ходом временных меток сохраняется техническим CSV в исходном порядке. Ограничение листа Excel — 1048576 строк с учётом заголовков.

## Заводские сведения

Ни команда 0, ни редактируемая дата команды 13 не подтверждают заводской серийный номер или дату изготовления. В текущих архивах таких подтверждённых полей нет: в ведомости и PDF указано «Нет данных». HART Device ID находится только в своём поле; тип HART подписан именно как код типа, не как предположительное название модели. Для контрольного Rosemount показан тип HART 0x2662, без догадки о заводской модели.

## PDF

A4 содержит сгруппированные таблицы:

- «Прибор»: параметр / значение, отдельно заводские поля и HART ID.
- «Измерения»: колонки PV/SV/TV/QV, строки единиц, минимума/максимума/среднего и количеств. Сохранена статистика принятых конечных GOOD/UNVERIFIED из 0.3.0; количество GOOD и UNVERIFIED разделено. UNVERIFIED не объявляется подтверждённым индивидуальным качеством. Среднее показано с девятью значащими цифрами, исходные значения Excel/CSV не округляются форматированием.
- «Конфигурация»: параметр / значение / единица / команда HART, включая ошибки необязательных чтений. Редактируемая HART Date подписана отдельно, не как дата изготовления.
- «События»: время UTC / категория / описание, включая исходные ошибки/восстановление и плохое качество.

Длинные таблицы продолжаются с повторением заголовков, строки не рисуются поверх следующей секции/нижнего колонтитула. Общий график сохраняет реальные разрывы и исходные шкалы; заголовки Y1/Y2/Y3 отделены от числовых делений, полные единицы и цвета вынесены в отдельную таблицу легенды под областью построения. Для многодневных данных на оси UTC отображается дата.

## Технический CSV

CSV остаётся дополнительным длинным экспортом: одна строка на исходную переменную. UTF-8 BOM, CRLF, исходные значения и статусы; разделитель выбирается `;` или `,`. Первая строка `sep=;` / `sep=,` явно задаёт его для Excel; имя файла и интерфейс также называют разделитель. Для программного чтения нужно пропустить строку директивы, например:

```python
pandas.read_csv(path, encoding="utf-8-sig", sep=";", skiprows=1)
```

Десятичная точка остаётся точкой. Для гарантированных типов чисел и дат в Excel используйте основной `.xlsx`.
