# HART-бро 0.3.0

Исходная версия — 0.2.1, испытанная пользователем с Метран-150 на Android 16. Идентификация 0099/9972/5FCA7F, команды 0/1/3/8/9/48/50, фрагментация, график, пауза и восстановление при отдельном разрыве подтверждены аппаратно для 0.2.1. Для 0.3.0 требуется новое комплексное аппаратное испытание.

## Подключение и сессии

`SessionController` запускает видимую `MonitoringService` после подтверждения подключения. Движок устанавливает secure Bluetooth Classic SPP, читает идентификацию и доступную конфигурацию, затем ждёт в состоянии READY. Временной истории и периодического измерительного опроса на этом этапе нет.

Кнопка «Начать сессию» повторно проверяет HART ID, читает актуальную конфигурацию, сбрасывает только согласованные возможности измерительного reader и создаёт новую временную историю с отдельным ID/временем/прибором. Перед каждой следующей сессией прибор проверяется заново; перестановка щупов не объединяет разные приборы. Автоматического обхода датчиков нет.

Пауза сохраняет сессию и Bluetooth, отмечает реальный разрыв. Сохранение во время опроса создаёт самостоятельный неизменяемый снимок и продолжает опрос. Завершение с сохранением либо без него удаляет только временную историю и оставляет исправное Bluetooth-соединение открытым. Если сокет закрыт или его пришлось закрыть при отмене блокирующей записи, требуется обычное новое подключение. Отдельное отключение коммуникатора доступно без действующей сессии. Начало/пауза/сохранение/завершение вынесены в закреплённую нижнюю панель; действия доступны при прокрутке графика, архива и длинного HEX.

Файлы: `MonitoringEngine.kt`, `SessionViewModel.kt`, `MainActivity.kt`.

## Фоновая работа и диагностика

Activity остаётся потребителем состояния. Сокет, сериализованная очередь и цикл опроса не принадлежат Activity/ViewModel scope. Видимая FGS типа `connectedDevice` удерживает приложение во время подтверждённого соединения. Partial wake lock теперь приобретается сразу после старта службы, защищая также первоначальное подключение; при паузе/готовности/ошибке освобождается, при опросе возобновляется с ограниченным сроком. Пустые доставки службе не создают новые подключения или сессии.

При `onDestroy` службы обмен останавливается и сокет закрывается; уже полученная временная история остаётся для явного решения пользователя. Раньше этот путь удалял временную историю. После смерти всего процесса автоматического рестарта нет, несохранённая временная история не превращается в постоянный архив.

HEX содержит ACTIVITY/SERVICE/PROCESS, переходы STATE с текстом причины, состояние сокета, время последнего TX/RX/измерения, длительность отсутствия измерений на переходе Activity. Транспорт сообщает начало/успех/ошибку RFCOMM connect, отмену записи, локальный close и окончание RX reader. Для локального закрытия указывается наблюдаемый инициатор; удалённое завершение или остановка Android не выдаются за доказанный источник внешнего сбоя. Рабочий HEX сохраняет лимит 16 МиБ и ручной TXT/share, подробный RX-CHUNK включается отдельно.

По присланным временным отметкам 0.2.1 единственная причина нестабильности не установлена: после одного ухода в фон был таймаут команды 9 с восстановлением, другие переключения проходили успешно, ещё один сбой возник при первоначальной идентификации. Эти факты не доказывают завершение FGS. Исправлены обнаруженные уязвимые пути жизненного цикла и расширена диагностика для аппаратного ретеста. Рабочий потоковый декодер и измерительный алгоритм 9→3→1 не переписаны, 60-секундный монотонный бюджет восстановления сохранён.

## Доступная конфигурация — только чтение

| Команда | Данные |
|---|---|
| 0 | HART revision, manufacturer code при наличии, полный device type/ID, device/software revisions; исходный ответ |
| 13 | Упакованные шестибитные TAG и description, исходные байты даты прибора |
| 15 | Код единицы настроенного диапазона; URV/LRV в правильном порядке ответа; damping; alarm, transfer function, write protection, private label; доступные analog-channel flags |
| 20 | Длинный TAG ISO Latin-1, для HART 6/7 |
| 48 | Исходная дополнительная диагностика; её изменчивые статусы не считаются настройками для сравнения |
| 50 | Назначения PV/SV/TV/QV в исходных HART-кодах |

Каждый параметр имеет номер команды-источника и код единицы, если применим. Сохраняются исходные байты ответов, их время, device status, response code и ошибки недоступных команд. Снимок явно частичный: нет DD/специфических параметров производителя. Неподдерживаемая/неполная/недостоверная необязательная команда не завершает весь мониторинг; I/O-потеря Bluetooth обрабатывается как потеря транспорта. Диапазон не выводится из тока или экстремумов графика. Обратный настроенный диапазон допускается. При отсутствии достоверной команды 15 — «Диапазон неизвестен».

На графике диапазон находится одной компактной строкой справа над областью построения. Физические пределы сенсора не читаются и не показываются.

## Журнал и совместимость

Новые архивы используют заголовок HBR2/version 2, включающий снимок конфигурации. Поля и типы записей измерений прежние: полная история, качество, исходные единицы, команда, дополнительный статус, реальное время получения, события и разрывы. Файлы version 1 версий 0.2.0/0.2.1 читаются без изменения байтов; исторические настройки для них не выдумываются. Обратное чтение новых архивов приложением 0.2.1 не обещается.

ID каждого снимка уникален. Время окончания — момент ручного сохранения, включая открытую паузу. Название (до 200 символов) и комментарий (до 10000) хранятся в атомарно заменяемом sidecar `.meta`, без перезаписи измерений. Измерения не сохраняются постоянно без действия пользователя. Список показывает дату/длительность, TAG или ID, производителя и диапазон; есть поиск по TAG/ID/названию, сортировка, редактирование, выбор нескольких записей, подтверждаемое удаление выбранных и очистка журнала. Экспортированные файлы при удалении записи не удаляются.

Сравниваются два сохранённых снимка либо сохранённый и текущий прочитанный снимок. Таблица выделяет только отличающиеся известные параметры. Отсутствующее поле — «Нет данных», текущие измерения не сравниваются как конфигурация. Текущий снимок относится к последнему чтению при подключении/начале сессии, а не к непрерывному наблюдению настроек.

## PDF и CSV

Экспорт локальный, без INTERNET permission, через стандартный Android выбор файла или отправку через FileProvider. Экспортируются только явно сохранённые проверки, независимо от подключения прибора.

PDF A4 содержит название/дату/ID проверки, сведения о приборе/коммуникаторе/диапазоне, статистику по всем исходным измерениям, общий график с UTC и числовыми шкалами/единицами/легендой, частичный снимок конфигурации, комментарий, события и ошибки. График сокращается с сохранением экстремумов; линии не проходят через зарегистрированные разрывы, плохое качество, отсутствие переменной или смену единицы. Статистика разделяется по переменной и коду единицы. В статистику входят конечные принятые GOOD и UNVERIFIED, их количества показаны отдельно: UNVERIFIED означает отсутствие индивидуального статуса в ответе прибора, а не доказанное хорошее качество. Остальные качества исключаются. Среднее считается по исходным принятым точкам, не по экранному графику и не по промежуточным значениям.

CSV содержит все исходные строки, включая недостоверные значения/качество; для ABSENT значение пустое. Поля: UTC timestamp, device ID, variable, received float, unit, HART unit code, quality, source command, variable code, raw status, device status и русское имя единицы. Float записывается round-trip строкой без форматного округления. UTF-8 BOM, CRLF, экранирование кавычек/переносов/разделителя. Можно выбрать `;` (Excel) или `,`; десятичный разделитель — точка, это явно указано в UI. При необходимости используйте импорт Excel «Из текста/CSV», UTF-8, выбранный разделитель, десятичная точка. Интерполяция и замена пропусков нулями отсутствуют.

## Границы

Сохранены applicationId `ru.hartbro.app`, основной вариант приложения и существующий ключ подписи опубликованных 0.2.0/0.2.1. Version name 0.3.0, versionCode 5. Нет команд записи (включая 38), сброса статусов, калибровки, USB OTG, Terminal, обхода датчиков, шаблонов/восстановления конфигурации или manufacturer-specific конфигурирования. Поддерживаются ревизии HART 5–7, polling address 0. Временная история ограничена 64 МиБ, HEX — 16 МиБ; при лимите пользователь получает явное сообщение.

Android/производитель телефона могут остановить процесс или запретить запуск службы из невидимой Activity. Приложение показывает фактическую ошибку, не обходит ограничения Android и не обещает продолжение после force-stop. Автоматические Android-сценарии используют только тестовый транспорт из androidTest; исправность реального VIATOR/Метрана они не доказывают.
