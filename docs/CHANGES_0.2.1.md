## Фоновая работа: что установлено, а что требует повторного испытания

В исходной 0.2.0 Activity не закрывала транспорт в onStop, а цикл уже принадлежал Application/foreground service. По одному описанию аппаратного симптома нельзя достоверно назвать единственную причину остановки на конкретном телефоне.

Найдены и устранены два риска: уведомление обновлялось при каждом изменении общего состояния, включая многочисленные RX-CHUNK; пустой onStartCommand останавливал службу даже при действующей сессии. Уведомление теперь зависит только от состояния мониторинга, ограничено по частоте; пустая доставка не завершает уже активную сессию. Отложенный onDestroy старого экземпляра службы не завершает сессию нового экземпляра (lease-проверка), а запрос stopService выполняется до разрешения нового подключения в UI. Владение сессией по-прежнему не связано с видимостью Activity, `stopWithTask=false`, режим START_NOT_STICKY, автоматического рестарта после гибели процесса нет.

Добавлены ACTIVITY/SERVICE/PROCESS-записи с временем начала/ID и причиной остановки; при Android 30+ записывается доступная причина предыдущего выхода из процесса. Они позволяют отличить остановку UI от реального прекращения опроса. Wake lock остаётся ограниченным по времени и возобновляется только при работе службы; на паузе/ожидании решения освобождается. При повторном аппаратном сбое нужен полный TXT, а не только скриншот графика.

Автоматические Android-тесты используют инструментальный MonitorConnection без Bluetooth-оборудования, проверяют две минуты Home, блокировку экрана, возврат/пересоздание Activity, то же время начала/ID, уведомление, историю и архивный Back. Тестовый источник находится только в `androidTest` и не включён в распространяемый APK. Проверка на эмуляторе не заменяет повторного испытания конкретной прошивки/VIATOR.

## Данные и подпись

Application ID `ru.hartbro.app`, min 29 / target 36; versionName 0.2.1, versionCode 4. Сохранён debug-ключ опубликованной 0.2.0. `HARTBRO_DEBUG_KEYSTORE` позволяет использовать существующее хранилище в доступном для сборки каталоге, не меняя ключ; значение — только локальный путь, приватные ключи не включены в Git. В CI без этой переменной используется стандартная debug-подпись runner, которая не обещает совпадения с опубликованным APK.

Формат заголовка архивов остаётся version 1; поля измерений не менялись. Разреженный индекс находится только в памяти и не переписывает архивы. Проверяется чтение legacy-записей 0.2.0; обратная совместимость новых событий с чтением в старой 0.2.0 не заявляется. Старые APK и отчёты не удаляются. Для обновления нужен опубликованный APK и установка поверх 0.2.0 без очистки данных; совместимость с 0.1.1 по-прежнему ограничена утратой её другого ключа.

Полное копирование большого TXT через Android Clipboard невозможно гарантировать из-за лимита Binder, поэтому текстовая копия ограничена 500 кБ с подписью об ограничении. Полный файл до лимита 16 МиБ сохраняется/передаётся средствами Android по явному действию. На диске нет автоматического архива всех испытаний: один рабочий журнал и до трёх временных файлов, созданных пользователем для share.
